# Проверка интерфейса — 5 ноября 2026

Режим: **full**. Проверены настольный сценарий загрузки WebM, настройки русского распознавания, получение результата, копирование, переходы к библиотеке моделей и обратно, переключение RU/EN. Основа интерфейса сохранена: React, TypeScript, Tailwind, Lucide и существующая светлая палитра. Мобильная версия исключена по запросу пользователя.

## Снимки и шаги

1. **Начальный экран — исправлен.** До изменений крупная пустая панель журнала занимала место результата, а четыре карточки этапов отображались до запуска. [Исходный экран](audit/01-before.png).
2. **Выбор файла и настроек — работает.** WebM загружен через настоящий диалог выбора файла; выбраны русский, `small`, Vulkan, четыре потока и восстановление пунктуации. Проверены состояния переключателей и блокировка таймкодов для SRT.
3. **Выполнение — работает.** После отправки отображается очередь, повторный запуск недоступен. Процесс завершился на встроенной AMD Radeon 780M, без перехода на CPU.
4. **Результат — работает.** Получен русский текст с пунктуацией; копирование показало подтверждение. Скачанный TXT совпадает с текстом API после удаления конечного перевода строки. [Результат](audit/02-after-result.png).
5. **Библиотека моделей — исправлена.** Убраны названия классов и внутренних API из заголовков, локализованы семейства и языковой охват, показана папка проекта. Переход туда и обратно сохраняет выбранный файл и результат. [Библиотека](audit/03-after-models.png).
6. **Настольное окно и язык — работают.** Итоговая сборка проверена при ширине окна 1280 пикселей без горизонтального переполнения; RU/EN меняет подписи без потери результата. Геометрия содержимого и доступной области совпадает: 1265 пикселей с учётом полосы прокрутки.

## Проверка и пределы

- Настоящий запуск корневого `start.ps1`, HTTP-проверка сервиса и production-интерфейса прошли. Проверены Windows PowerShell 5.1 и PowerShell 7, повторный запуск и остановка дерева процессов.
- `python -B -m unittest discover -s tests`: 54 теста проходят. Есть настоящий тест декодирования PyAV без модели и сети, тесты очереди, ошибок, GPU-адаптера и каталогов хранения.
- `npm run build` и `npm run lint` проходят. После обновления совместимых версий `npm audit` сообщает 7 moderate, 0 high, 0 critical; оставшиеся предупреждения относятся к цепочке TypeScript ESLint/minimatch.
- Реально проверены CPU `tiny`, Vulkan `tiny` и `small`, восстановление пунктуации SBERT и выгрузка результата. Веса, кэши моделей и временные загрузки направлены в папку проекта.
- Это не заявление о полном соответствии стандартам доступности. Проверены семантика, видимый фокус, состояния и геометрия; полноценная проверка экранным диктором не проводилась. Замедленное воспроизведение анимаций в панели DevTools не проводилось; новая анимация не добавлялась.
- Физическая NVIDIA-карта здесь отсутствует. Реализация Vulkan/CUDA и ошибки проверены кодом и тестами, аппаратный запуск подтверждён только на AMD Radeon 780M. Не проверены длинные многочасовые записи и установка на чистой Windows без уже существующих инструментов. Удалённые ссылки не проходили полный живой сценарий скачивания в этой проверке.

**Вердикт: Approve для проверенного настольного сценария локального WebM.** Непроверенные области перечислены выше; мобильная версия не входила в задачу.
