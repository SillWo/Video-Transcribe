# Зафиксированные вопросы учебного пилота

14 ноября 2026 года, до запуска извлечения и поиска. Это синтетические встречи с голосом Windows, а не пользовательские рабочие записи. Реальный пилот 2–3 записей требует отдельного набора вопросов пользователя и независимой проверки ответов.

| № | Вопрос | Ожидаемый факт и происхождение |
|---|---|---|
| 1 | К какому дню нужно подготовить инструкцию? | Пятница; только речь обеих встреч. |
| 2 | Какое значение режима проверки действовало после первого обсуждения? | «Вручную»; речь и экран первой встречи. |
| 3 | Как мы договорились заполнять это поле после последнего обсуждения и где его найти? | Карточка заявки → Параметры → Режим проверки → Автоматически; вторая встреча. |
| 4 | Как изменилась договорённость между обсуждениями? | Вручную → Автоматически; разные источники и даты двух встреч. |
| 5 | Какой адрес сервера показали? | qa-demo.internal; только экран второй встречи. Это вымышленный адрес учебного примера. |
| 6 | Какое значение лимита стоит в таблице и к какой строке оно относится? | 25; строка «Лимит повторов», заголовок «Значение». Только экран. |
| 7 | Какой идентификатор задачи показан на экране? | ARCH-427; буквальный поиск, не восстановление написания из речи. |
| 8 | Как называется программа, которую распознавание могло записать как «Дибивер»? | DBeaver; исходный ASR сохраняется, исправление и словарь имеют отдельное происхождение. |
| 9 | Какой номер кабинета согласовали? | В материалах факта нет. Не придумывать; дополнительные источники могут быть использованы только с указанием происхождения. |
| 10 | Какое меню открыли и какой вариант выбрали во втором обсуждении? | Меню поля «Режим проверки», вариант «Автоматически»; локальное изменение небольшой области кадра. |

Критерий ответа: верный факт, верное происхождение, открываемое подтверждение для каждой цитаты/экранного значения. Для отсутствующего факта — явный пробел. Программная проверка нахождения строк не равна оценке десяти ответов модели. Порог 9/10 применяется к полноценному пилоту, а не заявляется по unit-тестам.
