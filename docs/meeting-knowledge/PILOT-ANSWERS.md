Сохранённые ответы независимых запусков Codex на десять вопросов пользователя. Это материал для приёмки, не подтверждённая оценка 9/10. Речь, экран и вывод обозначены в самих ответах. Старые временные HTTP-ссылки заменены на долговечные ссылки того же ID и времени; в ответе 9 родитель уточнил видимое имя участницы по кадру 32:04; исходные ответы и события MCP сохранены без изменений в `.runtime/meeting-pilot/`.

Обработчик Windows подключён к текущему основному архиву. Формулировки «сейчас» и даты следует читать с оговорками ответов; отсутствие задачи или отчёта в записи не означает отсутствие её вне записанного эпизода. Не все экраны уже сохранены для работы без оригинала.

По встрече **«Гайд по задачкам в jira»**: MGMT — название проекта; подробно разобрано создание **KPI**, связанного с годовой целью. Поля сверены по реальным изображениям из `get_frames`.

**Практический порядок**

1. Нажмите **«Создать»**. Выберите **«Проект» → `MGMT (MGMT)`**, **«Тип задачи» → `KPI`**. Заполните **«Тема»*** и остальные поля со звёздочкой.

   **Сказано:** выбор команды и квартала формирует соответствующие метки автоматически; метку продукта нужно добавить вручную — от неё зависит папка в структуре.
