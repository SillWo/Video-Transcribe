# Проверка интерфейса по apple-design

Проверка настольного Video Transcribe, 6 ноября 2026. Проверены форма ссылки и локальных файлов, предварительный список, вкладки, очередь, обработка, ожидание, ошибка, прерывание, отмена, длинный результат, история и подтверждения. Основа — принципы обратной связи, контроля пользователя, привычного поведения, читаемости и аккуратности из apple-design.

## Проверено до исправлений

В браузере воспроизведены выход фокуса из диалога, отсутствие реакции на Esc, невидимый focus выбора качества и неверная подпись паузы. Сделаны снимки всех перечисленных состояний на искусственных данных; личные записи не использовались. Контраст рассчитан по относительной яркости цветов из CSS.

Ховер отдельно проверен в настоящем Electron с File, привязанным к исходному файлу: вложенные dragenter/dragleave не выключают подсветку; уход, blur и drop сбрасывают её; размеры блока не меняются; файл добавляется в список ровно один раз и задача автоматически не создаётся. Перетаскивание обычного текста не включает подсветку. Физический жест мышью из Проводника не проверялся; использованы DragEvent/DataTransfer и настоящий файловый мост Electron.

## Сохранённые решения

- Светлая рабочая поверхность, один синий акцент и привычное окно Windows соответствуют назначению утилиты.
- Редактор, история и настройки прокручиваются внутри окна; страница остаётся неподвижной.
- Стекло, размытие и пружинные перемещения не добавляются: в этом интерфейсе они не помогают чтению и управлению очередью.
- При снижении движения сохраняется статическая обратная связь. Мобильная компоновка не входит в продукт.

Окончательная проверка исправлений выполняется отдельно; этот список фиксирует обнаруженные причины и решения, а не сертификацию доступности.

## Итоговая проверка исправлений

Все восемь групп замечаний выше исправлены в `ui/src/App.tsx` и `ui/src/index.css`.

- `npm run build`, `npm run lint`, `npm run test:ui` — успешно, 7 тестов сохранения и переключения задач.
- Браузерная проверка обеих модальных операций: начальный фокус на безопасной кнопке, фоновые элементы недоступны, Esc закрывает свободный диалог и возвращает фокус. Во время запроса Esc не скрывает диалог; повторный запрос не отправляется; ошибка остаётся внутри диалога. Подтверждение с Enter также проверено.
- Переходы по вкладкам стрелками, Home и End сохраняют последние правки; медленное открытие показывает статус. Повторно проверены независимость черновиков, отказ переключения при ошибке сохранения, копирование и TXT, фоновое обновление истории и сохранение закрытых вкладок.
- Проверены правильные подписи паузы и потери связи, в том числе при пустом рабочем пространстве; после восстановления соединения состояние обновляется.
- Заголовки истории остаются видны при прокрутке. Действия выровнены в строку с достаточной шириной колонок.
- На 1920×1080, 1366×768, 1093×614 и 1024×768 документ не растёт по высоте и ширине. Основная кнопка доступна без прокрутки; внутренние настройки и редактор прокручиваются отдельно. В минимальном проверенном окне 1093×614 высота редактора составила 142 px.
- Ховер повторно проверен в Electron после остальных изменений. Переход цветов просмотрен на 10% скорости и при смене направления; размеры блока не меняются. Проверены `prefers-reduced-motion` и `prefers-contrast: more`: подсказка сохраняется, сильные движения не добавляются, границы усиливаются.

Проверка завершена: обнаруженные проблемы исправлены, повторные проверки прошли. Это проверка действующего упрощённого настольного интерфейса, без мобильной компоновки и без сертификации полной доступности. Физическое перетаскивание мышью из Проводника по-прежнему отдельно не проверялось.
