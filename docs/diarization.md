# Разделение речи по говорящим

## Назначение

Диаризация на базе **Nemotron-3-Diarization** необязательна, выключена по умолчанию и поддерживает до восьми говорящих. Она выполняется отдельным проходом после распознавания и не меняет выбранный ASR-профиль. Parakeet получает времена слов из native TDT-выхода; Qwen при запросе времён слов или диаризации использует отдельный **Forced Aligner 0.6B-hf** по общей подготовленной дорожке PCM16, mono, 16 кГц. Native времена не являются обещанием абсолютной точности.

Ограничение Forced Aligner в 11 языков, включая русский и английский, относится только к выравниванию Qwen. Для Parakeet отдельный выравниватель не используется. Если у native-выхода Parakeet или у выравнивания Qwen нет валидной границы слова, её время остаётся неизвестным: система не должна придумывать интервал. Полная проверка качества native времён Parakeet для всех языков не проводилась.

## Устройства и подготовка

Поддерживается Windows x64. Nemotron использует закреплённый **NeMo-Speech.cpp 0.3.0** и прежнюю GGUF-модель **Q8_0**. CPU и runtime для обнаруженных GPU, а также веса модели хранятся в `.runtime` проекта. Выбор GPU для Nemotron независим от устройства ASR: автоматически, CPU или конкретный обнаруженный GPU. NVIDIA обслуживается через CUDA, AMD и Intel — через Vulkan.

Явно выбранный для Nemotron GPU строгий: при ошибке задача завершается без перехода на CPU. Автоматический выбор может повторить только неудачный GPU-проход диаризации на CPU. Запрошенное устройство ASR так не меняется: если новый профиль явно выбрал GPU и ASR не смог выполнить smoke-check или инференс на нём, распознавание завершается ошибкой без CPU-повтора. Для Qwen Forced Aligner может повториться на CPU; причина записывается в диагностику. `start.ps1 -SetupOnly` заранее готовит Forced Aligner для Qwen, чтобы этот путь работал без сети после подготовки.

В ходе диаризации временные интервалы сопоставляются с уже распознанными словами: у Parakeet это native TDT-времена, у Qwen — результат Forced Aligner. Используются исходные веса Nemotron и, только для Qwen, Forced Aligner; перефразирование текста не выполняется. Исходный текст слов сохраняется точно, включая пробелы и пунктуацию, а валидные времена приводятся к общей временной шкале записи. Если время отсутствует или некорректно, интервал остаётся неизвестным; неизвестному слову назначается неизвестный говорящий. Native timestamps ещё не гарантируют абсолютную точность. Система не создаёт выдуманное время или назначение говорящего.

## Результат и редактирование

Диаризация добавляет этап **«Разделение по говорящим»** после распознавания и перед постобработкой. В текстовом результате остаются временные метки и подписи, например `[00:01:23] Говорящий 2: ...`. Имена — это номера кластеров только внутри одной записи: они не устанавливают личность и не связывают людей между разными записями. Неопределённость и наложения речи отмечаются в тексте. Для пустой тихой записи сохраняются пустой список сегментов и `turns: []`, без вымышленного языка или слов.

Русская пунктуация восстанавливается отдельной необязательной постобработкой. Для английского она пропускается, и интерфейс показывает уведомление. Файлы TXT и MD используют исходное имя медиафайла как основу имени результата. Редактируемое поле результата — отдельная сохранённая копия текста. Копирование и экспорт используют текущий черновик, включая ручные исправления; исходный медиафайл не изменяется.

## Проверка производительности

Измерения Nemotron ниже относятся к отдельному проходу диаризации, без ASR и остальной обработки. Это локальные единичные проверки, не гарантия скорости на другом оборудовании.

| Источник и устройство | Длительность записи | Время диаризации | Пиковый working set | Наблюдение |
| --- | ---: | ---: | ---: | --- |
| Встреча, CPU | 25 мин 38 с | 90.2268 с | 485,847,040 байт | Найдено 4 говорящих |
| Встреча, Radeon 780M / Vulkan | 25 мин 38 с | 7.5312 с | 521,748,480 байт | Найдено 4 говорящих; GPU compute engine доходил до 95% |
| Исходная запись, Radeon 780M / Vulkan, повторённая до двух часов | 2 ч synthetic input | 31.3924 с | — | Проверка длительности обработки и стабильности |

Границы говорящих для CPU и Vulkan немного различались. Двухчасовой synthetic-прогон повторял ту же запись и не является тестом реальной двухчасовой встречи или доказательством точности. NVIDIA и физические Intel GPU не проверялись; для них проверялись только автоматизированные ветви. DER и ручная оценка по размеченному эталону не выполнялись.

## Сквозная проверка

Исторические полные сценарии прошли на AMD Radeon 780M / Ryzen 7 8845H с 32 ГБ RAM: Qwen на английской речи с диаризацией на CPU; Qwen на русском минутном фрагменте встречи с автоматической диаризацией за 58.29 с; Qwen на 90-секундной записи с GPU-диаризацией за 18.67 с; тихая запись на CPU с диаризацией за 0.92 с. Эти результаты и прежние Parakeet-проходы с отдельным Forced Aligner относятся к старому пути и не описывают текущие native-времена Parakeet. Это единичные проходы, а не гарантия производительности или качества; полная приёмка текущего native-пути Parakeet отдельно не подтверждена.

Более подробные аппаратные условия, границы проверки ASR и источники измерений указаны в [описании профилей распознавания](asr-presets.md). Свежие проверки от 11–12 ноября хранятся локально в игнорируемой папке `.runtime/asr-validation`; исторические файлы из `.runtime/asr-evaluation` относятся к прежним изолированным экспериментам и не являются результатами этих полных сценариев.
